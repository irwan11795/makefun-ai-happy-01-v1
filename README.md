## The image

A joyful golden retriever puppy splashing in a sunlit puddle, water droplets sparkling like tiny rainbows around it. Its tongue is out and its eyes are closed in delight, completely lost in the moment. Bright, warm, and full of life — a happy moment, frozen in sunlight.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program copies `entry.png` (a JPEG, 1024x683, under 1 MiB) to the output directory deterministically, using only the Python standard library, with no network access. The copy is byte-verified against the source before the program reports success.
